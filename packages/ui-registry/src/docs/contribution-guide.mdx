# Contribution Guide

This guide explains how to contribute to shadcn-storybook-registry.

## Adding a New Story

How to add a new component story:

### 1. Create Story File

Create the story file:

```bash
# File path
src/registry/atoms/[component]-story/[component].stories.tsx
```

### 2. Follow Story Structure Pattern

Follow the CSF 3.0 format:

```typescript
import type { Meta, StoryObj } from "@storybook/nextjs-vite";
import { Component } from "@/components/ui/component";

/**
 * Describes the component's purpose and usage.
 */
const meta: Meta<typeof Component> = {
  title: "ui/Component",
  component: Component,
  tags: ["autodocs"],
  parameters: {
    layout: "centered",
  },
} satisfies Meta<typeof Component>;

export default meta;
type Story = StoryObj<typeof meta>;

/**
 * Default story description.
 */
export const Default: Story = {
  args: {
    variant: 'default',
    children: 'Example',
  },
};
```

### 3. Add Registry Entry

Add an entry to `registry.json`:

```json
{
  "name": "component-story",
  "type": "registry:component",
  "title": "Component Story",
  "description": "Interactive Storybook stories for component",
  "categories": ["atoms", "storybook"],
  "registryDependencies": ["component"],
  "dependencies": ["lucide-react"],
  "files": [{
    "path": "src/registry/atoms/component-story/component.stories.tsx",
    "type": "registry:component"
  }]
}
```

### 4. Build Registry

Build the registry:

```bash
npm run registry:build
```

### 5. Test Locally

Test the installation locally:

```bash
npx shadcn@latest add http://localhost:3000/v2/r/component-story.json
```

### 6. Verify in Storybook

Verify in Storybook:

```bash
npm run storybook
# Check the story at http://localhost:6006
```

### 7. Run Quality Checks

Run the quality checks:

```bash
npm run lint
npm run type-check
npm run test
```

## Code Style Guidelines

### TypeScript

- Use `satisfies Meta<typeof Component>`
- Prefer explicit types (`any` is not allowed)
- Define form schemas with `zod`

### Imports

```typescript
// Framework imports
import type { Meta, StoryObj } from "@storybook/nextjs-vite";

// ALWAYS use @ imports
import { Button } from "@/components/ui/button";

// Icons
import { ChevronRight, Loader2 } from "lucide-react";
```

### Story Naming

- Default: basic usage example
- Variants: the different variants (outline, ghost, secondary, etc.)
- States: Loading, Disabled
- Sizes: Small, Default, Large

### Play Functions

Add interaction tests:

```typescript
import { expect, userEvent, within } from "storybook/test";

export const InteractionTest: Story = {
  name: "when user clicks, should show success message",
  tags: ["!dev", "!autodocs"],
  play: async ({ canvasElement }) => {
    const canvas = within(canvasElement);
    await userEvent.click(canvas.getByRole('button'));
    await expect(canvas.getByText('Success')).toBeInTheDocument();
  },
};
```

## Documentation

### JSDoc Comments

Add a JSDoc comment to every story export:

```typescript
/**
 * Uses the outline variant to represent a secondary action.
 */
export const Outline: Story = {
  args: { variant: "outline" },
};
```

### Korean Comments

Write code comments in English:

```typescript
// 🎯 Purpose: validate user input
// 📝 Note: minimum of 6 characters required
```

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run all quality checks
5. Commit with proper message
6. Push to your fork
7. Create Pull Request
