# Getting Started

Welcome to the **shadcn-storybook-registry**!

This project is a registry that provides Storybook stories for shadcn/ui components.

## Installation

Use the shadcn CLI to install the component stories you need:

```bash
npx shadcn@latest add http://localhost:3000/v2/r/button-story.json
```

## Usage

Installed story files can be used in Storybook straight away:

```tsx
import { Button } from "@/components/ui/button";

export default function App() {
  return <Button variant="default">Click me</Button>;
}
```

## Available Components

46 component stories are currently available:

### UI Components (46)
- **Form**: Button, Input, Checkbox, Radio, Select, Switch, Textarea, Label
- **Layout**: Card, Separator, Aspect Ratio, Resizable, Scroll Area
- **Navigation**: Accordion, Tabs, Breadcrumb, Navigation Menu, Menubar, Sidebar
- **Overlay**: Dialog, Sheet, Drawer, Popover, Tooltip, Hover Card
- **Feedback**: Alert, Progress, Skeleton, Sonner (Toast)
- **Data Display**: Badge, Avatar, Table, Calendar, Date Picker, Chart
- **Interactive**: Slider, Toggle, Toggle Group, Command, Combobox, Context Menu, Dropdown Menu

### Design Tokens (5)
- Color, Typography, Spacing, Shadow, Radius

### Templates (1)
- Dashboard Template

## Features

✅ **CSF 3.0 Format**: the latest Storybook story format
✅ **TypeScript**: full type safety
✅ **Light/Dark Mode**: theme switching support
✅ **Play Functions**: automated interaction tests
✅ **Args Controls**: dynamic props manipulation
✅ **Accessibility**: WCAG 2.1 AA compliant

## Development

Use the following commands for local development:

```bash
# Run the Storybook development server
npm run storybook

# Build the registry
npm run registry:build

# Run the tests
npm run test
```
