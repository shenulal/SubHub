# Design Principles

The core design principles of shadcn-storybook-registry.

## Accessibility First

**WCAG 2.1 AA** compliance is the top priority.

- ✅ Keyboard navigation support
- ✅ Screen reader friendly
- ✅ Semantic HTML
- ✅ ARIA attributes
- ✅ Color contrast compliance

Every component is checked for accessibility with the Storybook A11y addon.

## Responsive Design

A **mobile-first** approach supports every screen size.

- 📱 Mobile (375px)
- 📱 Tablet (768px)
- 💻 Desktop (1920px)

Use the Storybook Viewport addon to test components at different screen sizes.

## Dark Mode Support

Full **light/dark theme** support:

- 🌞 Light mode (default)
- 🌙 Dark mode
- 🎨 Easy customisation through CSS custom properties
- 🔄 Seamless theme switching

Use `@storybook/addon-themes` to switch themes instantly in Storybook while testing.

## Design Tokens

A structured design token system:

### Color System
- **Primary**: brand colour
- **Secondary**: secondary colour
- **Accent**: accent colour
- **Destructive**: warning/error states
- **Muted**: backgrounds and disabled states

### Typography Scale
- `xs`: 0.75rem (12px)
- `sm`: 0.875rem (14px)
- `base`: 1rem (16px)
- `lg`: 1.125rem (18px)
- `xl`: 1.25rem (20px)
- `2xl` ~ `9xl`: larger sizes

### Spacing System
- 0.5rem ~ 8rem
- Based on the Tailwind CSS spacing scale
- Consistent margins and padding

### Shadow System
- `sm`, `base`, `md`, `lg`, `xl`, `2xl`
- Conveys depth
- Optimised separately for light and dark mode

### Radius System
- `sm`, `base`, `md`, `lg`, `full`
- Consistent corner rounding

## Component Composition

Applies **Atomic Design** principles:

- **Atoms**: basic UI elements (Button, Input, Badge)
- **Molecules**: composed components (Form Field, Card)
- **Organisms**: complex UI blocks (Navigation, Sidebar)
- **Templates**: page layouts

## Type Safety

Full **TypeScript** support:

- `satisfies Meta<typeof Component>` pattern
- Explicit return types
- Strict mode enabled
- Makes maximum use of type inference

## Testing

**Automated testing** strategy:

- ✅ Interaction tests with play functions
- ✅ Vitest unit tests
- ✅ Playwright browser tests
- ✅ Automated accessibility checks

## Documentation

**Clear documentation**:

- JSDoc comments are mandatory
- Storybook Autodocs applied to 100% of components
- Clear English descriptions
- Usage examples included

## Performance

**Optimised performance**:

- Tree-shaking support
- Lazy loading
- Minimal bundle size
- React 18/19 compatible
